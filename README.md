# 🚀 AlgoClass

A modern **LeetCode-style coding practice platform** with a complete **Teacher–Student classroom management system**.

AlgoClass allows students to practice coding problems, track their progress, join classes, complete assignments, and participate in challenges. Teachers can create classes, monitor student performance, assign coding problems, and analyze student progress.

---

## ✨ Features

### 🔐 Role-Based Authentication

The platform supports three user roles:

- 🎓 Student
- 👨‍🏫 Teacher
- 🛡️ Admin

Each user gets access only to the features allowed for their role.

---

## 🎓 Student Features

- Solve coding problems
- Access 1000+ coding problems
- Filter problems by:
  - Difficulty
  - Topic
  - Solved Status
- Run and submit code
- Track coding progress
- Join teacher classes using a unique class code
- View assignments
- Participate in weekly challenges
- Track coding streaks
- Set personal coding goals
- Earn badges and achievements
- View class leaderboard
- View topic-wise performance
- Receive announcements and notifications
- Problem-solving timer
- Copy/Paste protection during coding practice

## 👨‍🏫 Teacher Features

- Create and manage classes

- Add and monitor students

- Set assignment deadlines
- Create weekly coding challenges
- Post announcements
- Monitor student progress

- Identify inactive students
- View student achievements

## 🛡️ Admin Features
